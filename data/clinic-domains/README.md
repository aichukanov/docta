# Домены клиник

Юзер выкупает освободившиеся домены клиник. Эта папка показывает, какие домены уже свободны,
какие скоро освободятся и у каких сайт умер, хотя домен ещё занят.

## Файлы

- `report.md` — отчёт последнего прогона по разделам: свободны, скоро освободятся, мертвы или
  припаркованы, перекуплены под спам, истекают у наших клиник.
- `state.json` — состояние по каждому домену. `statusSince` — с какого прогона домен в этом
  статусе: свободный домен с давним `statusSince` никто не подхватывает.
- `decisions.json` — ручной файл:
  - `watch` — домены, которых нет ни в БД, ни в Google, но за которыми надо следить;
  - `decided` — что решено по домену: `{ "drsenad.me": { "decision": "куплен", "note": "…" } }`.
    Такой домен уходит из основных разделов отчёта в «Решения».

## Прогон

```
node scripts/clinics/check-clinic-domains.mjs
node scripts/clinics/check-clinic-domains.mjs --only=pjerotic.me,drsenad.me
```

Занимает около 5–7 минут. Запросы к whois.nic.me идут по одному, потому что параллельные
реестр обрывает. Гонять раз в месяц, вместе с журналом прайсов.

**Откуда домены:**

- сайты клиник в локальной БД;
- `websiteUri` всех мест в `data/google-places/`, включая аптеки;
- сайты кандидатов из `data/clinic-candidates/candidates.json`;
- `decisions.json → watch`.

Домены соцсетей, агрегаторов и конструкторов сайтов пропускаются.

**Как проверяется домен:**

| Зона | Чем проверяется |
|---|---|
| `.me`, `.rs`, `.ru` | WHOIS: у `.me` нет RDAP в реестре IANA |
| остальные | RDAP по бутстрапу IANA |

После регистрации проверяются DNS и ответ сайта: код, заголовок, признаки парковки и казино-спама.

## Статусы

| status | Значение |
|---|---|
| `free` | Реестр не знает домена — можно регистрировать. |
| `pending_delete` | В реестре статус pendingDelete или redemptionPeriod — освободится в ближайшие недели. |
| `expired` | Срок регистрации прошёл, домен в льготном периоде. |
| `expiring_dead` | Истекает в ближайшие 45 дней, а сайт мёртв или припаркован. |
| `dead` / `parked` | Домен занят, сайт не работает или стоит заглушка регистратора. |
| `hijacked` | В заголовке страницы казино или слоты: домен уже перекуплен. |
| `expiring` | Истекает скоро, но сайт живой. В отчёте показывается только для наших клиник. |
| `ok` | Всё в порядке. |
| `unknown` | WHOIS или RDAP не ответил. |

## Ценность домена

Нужен не любой свободный адрес, а **бывший сайт клиники, на который остались ссылки**.

**Был ли сайт.** Для свободных и умирающих доменов скрипт смотрит Wayback Machine:
`state.json → wayback`, в отчёте колонка «Сайт в архиве». Если снимков нет, сайта на домене
не было: адрес вписан в карточку Google, но сайт не запускали. Такие домены вынесены в
отдельный раздел. Один снимок и одна страница обычно означают заглушку.

**Кто ссылается.** Ссылки собираются вручную в `decisions.json → research`:

```json
"pjerotic.me": { "checked": "2026-10-08", "links": ["карточка Google Maps …"], "note": "…" }
```

- Самая частая живая ссылка — поле «сайт» в карточке Google Maps. Клиника его не убрала, и
  клики с карты уходят на мёртвый домен.
- Остальное ищется поиском по имени домена и проверкой каталогов: ordinacije.me,
  stomatologija.me, foursquare, vymaps. Каталоги обычно ссылаются не на сайт клиники, а на
  свою карточку.

Полный ссылочный профиль, то есть число доноров и их вес, даёт только Ahrefs или Semrush.
Коннектор Semrush в claude.ai есть, но не авторизован.
