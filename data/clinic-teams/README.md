# Карта списков врачей на сайтах клиник

Где на сайтах клиник опубликован состав врачей, и как он соотносится с
привязками `doctor_clinics` в нашей БД. Карта нужна, чтобы держать списки врачей
актуальными. Устроена так же, как `data/clinic-pricelists/` для прайсов.

Срез: **2026-10-02**, локальная БД. В срезе 103 сайта и 1814 привязок врачей.
Привязки SmartMed Kotor исключены: его врачи отвязываются в
`server/sql/update-clinics-2026-10-pricelist-map.sql`. Все 103 сайта проверили
вручную субагенты, curl'ом по сырому HTML, wp-json, JSON API и бандлам.
29 клиник без сайта (около 60 привязок) не проверялись.

## Статус

Составы 40 записей карты синхронизированы с сайтами 2026-10-06 и применены. В map.json у них поле `synced`; сводка и хвосты — [BACKLOG.md](BACKLOG.md), раздел «Синхронизация составов 2026-10-06». Цифры ниже — срез до синхронизации.

## map.json

По записи на сайт. Поля:

| Поле | Что внутри |
|---|---|
| `clinics[]` | id, slug, название, `dbDoctors` — сколько врачей у нас привязано |
| `status` | `team_page` — список врачей; `doctor_pages` — только страницы отдельных врачей; `doctors_on_service_pages` — врачи на страницах отделений или услуг; `partial_team` — 1–3 имени, обычно владелец; `no_team_list` — имён нет; `site_down` |
| `coverage` | `full` / `sampled` / `none` |
| `teamSources[]` | URL, тип (html, wp-json, json-api, pdf) и `date_hint` — **по этим адресам делается перепроверка** |
| `siteDoctors[]` | имя без титула, титул, специальность, URL, филиал, `role` (врач / не врач) |
| `matched[]` | наш slug ↔ имя на сайте |
| `possibleMatches[]` | сомнительные пары с объяснением, требуют решения |
| `dbOnly[]` | наши привязки, которых на сайте нет |
| `dbOnlyIsEvidence` | `true`, если сайт даёт полный список и отсутствие врача на нём — сигнал, что он ушёл. `false` при `partial_team`, `no_team_list`, `site_down` и там, где сайт часть врачей не публикует в принципе (причина — в `dbOnlyCaveat`) |
| `siteOnly[]` | врачи с сайта, которых у нас нет |
| `checked`, `notes`, `lastChecked` | что смотрели и особенности сайта |
