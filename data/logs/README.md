# Снимки логов прода (pm2)

Два снимка одного и того же набора файлов pm2 (`docta-error-4..7`, `docta-out-4..7` — четыре воркера кластера). Хранятся gzip'ом: 6,2 МБ сырых сжимаются в ~330 КБ, логи очень повторяющиеся.

| Каталог | Снят | Источник |
|---|---|---|
| `2026-07-23/` | 2026-07-23 11:21 | `E:\pet\docta.me\logs` |
| `2026-07-30/` | 2026-07-30 09:31 | `E:\pet\svad\server-logs\log-260730` |

**Ключевое свойство: снимок от 23.07 — побайтовый префикс снимка от 30.07** (проверено `cmp` по всем четырём error-файлам, pm2 только дописывает). Значит вычитанием получается чистое окно 23.07 → 30.07 — ровно то, чего не хватало для открытого вопроса «хвост падений за 23–27.07» в `docs/audit/seo-2026-07.md`.

Смещения префикса (байт), если понадобится повторить:

| Файл | Размер на 23.07 |
|---|---|
| `docta-error-4.log` | 787 776 |
| `docta-error-5.log` | 788 860 |
| `docta-error-6.log` | 772 884 |
| `docta-error-7.log` | 825 939 |

```sh
# восстановить окно 23.07–30.07 для воркера 4
gunzip -c 2026-07-30/docta-error-4.log.gz | tail -c +787777
```

**Таймстемпов в логах нет** — pm2 писался без `--time`. Датировка возможна только через границу снимков; внутри окна порядок событий известен, точное время — нет. Если логи ещё понадобятся для диагностики по датам, включить таймстемпы в pm2.
