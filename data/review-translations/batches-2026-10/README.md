# Переводы отзывов: пачки 2026-10

`todo/batch-NNN.json` — что перевести, `done/batch-NNN.json` — перевод (то же
имя файла). Собирает и пишет SQL `scripts/reviews/review-translations.mjs`.

## Порции

`portions.json` — пачки, сгруппированные в порции по ~0,7 млн токенов (оценка
по пробной batch-001: 86 тыс. токенов на 14,5 КБ входа). Запускаются по
одной, по порядку: на каждую пачку порции — свой агент, параллельно; агент
читает этот README, пишет `done/batch-NNN.json` и сверяет, что все `need`
заполнены. После порции:

```bash
node scripts/reviews/review-translations.mjs status --dir data/review-translations/batches-2026-10
```

SQL — когда переведено всё (или промежуточно, по готовым пачкам: COALESCE
делает повтор безопасным):

```bash
node scripts/reviews/review-translations.mjs sql --dir data/review-translations/batches-2026-10 --out server/sql/reviews-google/translations-2026-10.sql
```

**`extract` не перезапускать посреди работы**: он пересобирает `todo/` из
базы, номера пачек сдвинутся, и готовые `done/` перестанут им соответствовать.

## Вход

Массив элементов:

```json
{ "key": "r:places/…", "kind": "review", "lang": "hr", "script": "latn",
  "text": "оригинал", "need": ["sr_cyrl", "en", "ru", "de", "tr"] }
```

`kind` — `review` (отзыв пациента) или `reply` (ответ клиники на отзыв).

## Выход

Один JSON-объект на всю пачку, ключ — `key` элемента, внутри — **ровно языки
из `need`**:

```json
{ "r:places/…": { "sr_cyrl": "…", "en": "…", "ru": "…", "de": "…", "tr": "…" } }
```

Все элементы пачки, ни одного пропуска. Файл — валидный JSON (кавычки внутри
текста экранировать).

## Языки

- `sr` — сербский **латиницей** с диакритикой (č ć ž š đ), иекавица, как
  говорят в Черногории: «mlijeko», «vrijeme», «lijepo».
- `sr_cyrl` — тот же сербский **кириллицей** (иекавица). Не механическая
  транслитерация: имена людей транслитерируются (Marko → Марко), а названия
  клиник, бренды, латинские аббревиатуры (CT, MR, PRP, IVF), e-mail и ссылки
  остаются латиницей.
- Если оригинал боснийский/хорватский/сербский латиницей и в `need` нет `sr` —
  `sr_cyrl` делается из оригинала, с исправлением на иекавицу только там, где
  это сербская форма, а не опечатка автора.
- Если оригинал сербский кириллицей (`script: cyrl`) и нужен `sr` — латиница
  того же текста.
- `en`, `ru`, `de`, `tr` — естественный перевод, не дословный.

## Правила

- Смысл, тон, оценочность — как в оригинале; не смягчать жалобы и не усиливать
  похвалу. Эмодзи, «!!!», капс — сохранять.
- Имена врачей и персонала не переводить, только склонять по правилам языка
  (Dr Marko → «доктор Марко», «доктору Марко»); названия клиник — как есть.
- Опечатки и разговорность оригинала в переводе не воспроизводить — переводить
  смысл грамотным языком.
- Ничего не добавлять от себя: ни пояснений, ни «[перевод]», ни примечаний.
- Отзыв на другом языке (pl, uk, fr, it…) переводится на все языки из `need`.
