# Промо и размещения

Папка под бесплатные размещения docta.me во внешних сообществах: тексты постов,
скриншоты, проверенные цифры и результат. Одно размещение — одна подпапка
`<канал>-<год>-<месяц>/`.

Зачем документировать: у проекта нет ни одной заработанной ссылки на сам домен
(см. пункт 6 в [`../audit/seo-2026-07.md`](../audit/seo-2026-07.md)), и каждое
размещение — единица работы по этому пункту. Плюс тексты переиспользуются:
цифры, формулировки и грабли не нужно выяснять заново.

## Конвенции

- **Цифры в посте сверять с продом, а не с локальной БД.** Локальная копия
  расходится в обе стороны: где-то опережает прод непринятыми импортами, где-то
  отстаёт. Читатель кликнет и сравнит.
- **Не переписывать факты в удобную сторону.** Если утверждение требует
  оговорки, которая не влезает в лимит — пункт выкидывается целиком, а не
  упрощается до неверного (так поступили с тарифами ФЗОЦГ, см. историю ниже).
- **Лимиты Телеграма:** обычное сообщение 4096 символов, подпись к фото или
  альбому **1024** (2048 с Premium). Если пост идёт с картинками — бюджет 1024.
- **Считать символы, а не байты.** `wc -m` в Git Bash при не-UTF-8 локали
  возвращает байты, и кириллица удваивается: реальные 1020 символов выглядят
  как «1812». Считать так:
  ```bash
  node -e "const s=require('fs').readFileSync(process.argv[1],'utf8').replace(/\n+$/,''); console.log([...s].length)" post.txt
  ```
- **Скриншоты снимать скриптом с прода** — воспроизводимо и без ручной
  обрезки: [`telegram-polako-2026-07/make-screenshots.mjs`](telegram-polako-2026-07/make-screenshots.mjs).
