# Дизайн-система как зависимость

Как `@ach/ui-kit` попадает в сборку и почему именно так. Пакет общий для
docta.me и svad, живёт отдельным репозиторием
`https://github.com/aichukanov/ui-kit` (приватный).

## Как объявлена зависимость

```jsonc
// package.json
"@ach/ui-kit": "git+https://github.com/aichukanov/ui-kit.git#main"
```

Точная версия пинуется **в `package-lock.json`**: npm пишет туда полный SHA
коммита. Поэтому `npm ci` на сервере всегда ставит ровно тот код, который был
на момент коммита лока, — а `npm install` локально подтягивает новый `main`
и перезаписывает лок.

### `git+ssh://` в локе — это нормально, не пугайтесь

В `package.json` указан `git+https://`, но в `package-lock.json` npm запишет
`git+ssh://git@github.com/...`: он нормализует URL известных хостингов.
Ключа SSH для этого НЕ нужно — GitHub-спеки npm считает hosted и откатывается
на HTTPS сам. Проверено: `git ls-remote ssh://git@github.com/...` падает
с `Permission denied (publickey)`, а `npm pack` по тому же ssh-спеку из лока
проходит. Так что переписывать лок руками и заводить SSH-ключи не надо.

Что действительно нужно серверу — те же HTTPS-креды, которыми делается
`git pull`, плюс доступ именно к репозиторию `ui-kit`.

## Как деплоить

Ничего нового в процедуру добавлять не нужно:

```sh
# на сервере (Linux)
git pull
npm ci          # склонирует @ach/ui-kit на SHA из package-lock.json
npm run build
pm2 restart docta
```

**Что проверить при первом деплое после перехода:** доступ сервера к
приватному репозиторию пакета. `git pull` работает по HTTPS с сохранёнными
кредами — их же использует npm. Но если доступ выдан deploy key, привязанным
только к репозиторию `docta`, до `ui-kit` он не достанет, и `npm ci` упадёт
на клонировании. Лечится добавлением пакета в тот же доступ.

## Почему не другие варианты

**`file:../../ui-kit`** (было на старте) — путь наружу репозитория. На сервере
такой папки нет, `npm ci` падает. Годится только для локальной разработки.

**git submodule** — выглядит удобнее, но у него тихий отказ: `git pull`
submodule НЕ обновляет. Забыли `git submodule update --init` — прод собрался
со старой дизайн-системой и никто не заметил. У git-зависимости этот отказ
громкий: `npm ci` либо поставит залоченный SHA, либо упадёт.

**Публикация в npm-реестр** — лишняя инфраструктура и токен на сервере ради
двух потребителей.

**Вендоринг (копия кода в каждом репозитории)** — обнуляет смысл отдельного
пакета: правки пришлось бы синхронизировать руками.

## Локальная разработка пакета

Пуш ради каждой правки компонента — плохой цикл. Для работы над пакетом
подменяем зависимость симлинком на рабочую копию:

```powershell
cd e:/pet/ui-kit
npm link                      # регистрирует пакет глобально
rm -r -force node_modules     # см. ловушку ниже

cd e:/pet/docta.me/nuxt
npm link @ach/ui-kit          # подменяет зависимость симлинком
```

**Ловушка:** `npm link` в папке пакета ставит его peer-зависимости и создаёт
там `node_modules` со вторым экземпляром `vue`. Глобальная регистрация линка
от этой папки не зависит, поэтому её надо сразу удалить — иначе получаем два
Vue на диске, а это сломанные реактивность и `provide/inject`. Симлинк
в приложении при этом продолжает работать.

Дальше правки в `e:/pet/ui-kit` видны сразу, без коммитов. `package.json`
при этом НЕ меняется — линк живёт только в `node_modules`.

Линк слетает после любого `npm ci` или `npm install` — тогда повторить
`npm link @ach/ui-kit`. Проверить текущее состояние:

```powershell
# ReparsePoint в атрибутах = линк активен, Directory = обычная установка
(Get-Item node_modules/@ach/ui-kit).Attributes
```

Закончив, отправить изменения и обновить лок:

```powershell
cd e:/pet/ui-kit
git push

cd e:/pet/docta.me/nuxt
npm install @ach/ui-kit      # перезапишет SHA в локе
```

## Что пакет требует от приложения

- `modules: ['@ach/ui-kit/nuxt']` — модуль сам подключает токены и регистрирует
  компоненты с composables автоимпортом.
- `css: ['@ach/ui-kit/element-plus-bridge.css']` — пока в проекте жив
  Element Plus. Отдельной строкой, чтобы удаляться вместе с ним.
- Приложение **не объявляет** `--color-*`, `--spacing-*` и прочие токены у себя:
  локальный блок молча перебьёт дизайн-систему. Именно так svad и разошёлся
  с docta.me, пока набор копировался руками.
