## Юридические риски (главные)

| Риск | Митигция |
| --- | --- |
| Иск о защите деловой репутации / клевете от клиники | Только стандартные формулировки-факты без правовых квалификаций; два уровня достоверности с честной подписью «не подтверждено»; «подтверждено» — только при наличии у редакции документов; документы-основания хранить вне репозитория (переписка, чеки, скриншоты) на случай спора; право на ответ (FR-3.4/3.5) реализовано и видно |
| Давление на клинику выглядит как конфликт интересов (кейс затронул семью основателя) | В статье кейс подан анонимно от лица пациентки, позиция клиники изложена; решение о раскрытии конфликта интересов в статье — за пользователем (см. открытые вопросы) |
| Ошибочная жалоба (перепутали клинику, спор урегулирован) | `is_active = 0` снимает бейдж мгновенно; история в БД; контакт для оспаривания в подвале раздела |
| Клиника «чинит» репутацию накруткой 5★ | На порядок выдачи docta.me не влияет: закреплённый отзыв всё равно первый, бейдж от рейтинга не зависит |

## Продуктовые риски

- **Бейдж пугает сильнее, чем информирует** — на карточках он warning (янтарный), не danger;
  текст «Осторожно», не «Скам». Следим за CTR карточек с бейджем.
- **Разделом перестанут заниматься** — раздел виден публично, пустых «заглушек» нет (секция
  не рендерится без жалоб), поэтому протухание = отсутствие раздела, а не мусор.
- **Смешение с «Визит подтверждён»** — тексты бейджа отзыва обобщаются (FR-2.2), отдельного
  второго бейджа не вводим.

## Метрики успеха

1. `reputation_viewed` (Mixpanel) — раздел читают: >5% просмотров страницы клиники с бейджем.
2. CTR карточки клиники с бейджем в каталоге — ожидаем снижение (это цель: информированный выбор),
   контролируем, что без обвала всего листинга.
3. Переходы на статью-разбор из раздела «Репутация».
4. Обращения клиник на contact@docta.me по поводу бейджа (признак, что механизм заметили;
   каждое — повод перепроверить досье).

## Открытые вопросы (решает пользователь)

1. **Раскрытие конфликта интересов в статье.** Кейс — семья основателя docta.me. Журналистская
   практика — раскрывать («случай произошёл с семьёй члена редакции»); это же защищает от обвинения
   в скрытой мотивации. Решить до публикации статьи.
2. **Снятие бейджа при урегулировании.** Предложение: если клиника вернула деньги/урегулировала —
   жалобу не деактивировать молча, а переводить в состояние «урегулировано» (потребует третьего
   статуса в ENUM). В фазе 1 — просто `is_active = 0`.
3. **Бейдж в шапках подстраниц клиники** (услуги/анализы/врачи) — FR-4.3.7, решить на итерации 3
   по месту.
4. **Порог для QUALITY_COMPLAINTS (код 6).** Жалобы на качество лечения — самая субъективная
   категория; предлагается заводить её только как `unconfirmed` и никогда не давать по ней бейдж
   (т.е. бейдж де-факто только по «денежным» кодам 1–5). Зафиксировать решение.
5. **Отметка на карте.** Сейчас бейдж только в попапе; красить сам маркер не предлагаем
   (перегруз карты). Подтвердить.
