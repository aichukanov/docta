# Графики приёма врачей с сайтов клиник

> Статус: **📋 Backlog, ценность сомнительная, стоимость высокая.** Обсуждено 2026-10-08.
> Сделано только дешёвое: ссылка на график на сайте клиники (миграция 053).

## Что есть у клиник

Часть клиник публикует графики работы врачей на своих сайтах. Инвентаризация —
`teamSources` в [data/clinic-teams/map.json](../../data/clinic-teams/map.json).

| Клиника | Формат | Период | Постоянный адрес |
|---|---|---|---|
| Hipokrat (70/71/72) | серверный HTML, таблица «врач × день × часы» по филиалам | скользящее окно «сегодня + 6 дней» | да, `/hipokrat/raspored` |
| КЦЦГ (65) | HTML, raspored ordiniranja по амбулаториям | правится раз в несколько месяцев | да |
| ДЗ Подгорица (140) | помесячные PDF по службам (IDO, IDD, IDŽ, центры) | месяц; ссылки на часть служб месяцами пустые | да, страница-оглавление |
| Brezovik (139) | HTML, 8 пульмологов | не меняется с марта 2026 | да |
| ДЗ Херцег-Нови (80) | пост WP каждую неделю | неделя | **нет**: рубрика общих новостей |
| Masoničić (58) | фото приказа в посте | месяц | **нет**, и нужен OCR |
| ДЗ Тиват (134) | смены на главной, сокращённые имена «Dr M.Kosić» | неделя | главная = поле `website` |
| Primus (40), ДЗ Бијело Поље (87) | один приходящий врач / только гинекологи | — | частично |

Две особенности:

- **В частной клинике графики — это в основном приходящие специалисты.** У Hipokrat
  в графике 5 человек при 27 врачах в базе. Отсутствие врача в графике ничего не значит.
- **В госклиниках расписаны смены izabranih doktora** (утро/вечер). Это важно
  тому, кто к врачу уже прикреплён, а не тому, кто врача выбирает.

## Сделано: ссылка

Колонка `clinics.doctor_schedule_url` (миграция
[053](../../server/sql/migrations/053-clinic-doctor-schedule-url.sql)), поле в
админке клиники, строка «График приёма врачей на сайте клиники» в секции «Часы
работы» страницы клиники. Секция показывается и без часов работы, если ссылка
есть. Клики уходят в Mixpanel как `contact_clicked` с `contact_type =
doctor_schedule` — по ним видно, нужен ли кому-то график вообще.

Заполнены только постоянные адреса: Hipokrat ×3, КЦЦГ, ДЗ Подгорица, Brezovik.

## Не сделано и почему

### 1. Показ часов приёма у врача и в карточке клиники

Самое привлекательное для пользователя («невролог в Никшиче по понедельникам
09–14») и самое дорогое.

- **Свежесть.** График недельный или месячный. Устаревший график вреден:
  пациент придёт к закрытой двери. Значит, нужна **автоматическая запись в
  прод** раз в неделю, а у нас весь SQL применяется руками через туннель.
  Это смена модели работы с данными ради 3–6 клиник.
- **Свой парсер на каждый источник** (HTML, пост WP, PDF, фото), и каждый
  ломается при смене вёрстки. Нужны мониторинг поломок и сопоставление имён
  с нашими врачами (сокращения «Dr M.Kosić», латиница/кириллица, опечатки).
- **Защита от устаревания на фронте:** дата снимка рядом с часами, скрытие
  через N дней без обновления. Без этого фичу выпускать нельзя.
- schema.org `hoursAvailable` у `Physician` — то же требование к свежести,
  выгода для SEO не доказана.

Оценка: модель данных (`doctor_clinic_schedule`: врач × клиника × дата ×
интервал × дата снимка) + 2–3 парсера + задача по расписанию с записью в прод +
UI с датой и протуханием. Несколько дней работы и постоянное сопровождение.

### 2. Графики как источник для уборки данных

Дешевле и полезнее для нас, чем для пользователя, но тоже не бесплатно.

- **Привязка к филиалам Hipokrat.** Сейчас у 70/71/72 по 27–28 врачей — весь
  штат сети привязан ко всем трём филиалам: страница `/doctors` их не делит.
  График — единственный источник, где виден филиал. Нужно 4–6 недельных
  снимков подряд, ежемесячного прогона не хватит: окно 7 дней, врачи, которые
  принимают по очереди, выпадут.
- **Сигнал «врач работает»** для [check-doctor-teams.mjs](../../scripts/clinics/check-doctor-teams.mjs):
  сейчас для страниц графика в журнале хранится только хеш. Можно доставать
  имена и копить «замечен в графике филиала X, дата». Сигнал только
  положительный.
- Начинать с Hipokrat и ДЗ Херцег-Нови — их проще всего разбирать.

### 3. Ссылки на недельные посты

ДЗ Херцег-Нови и Masoničić публикуют график новым постом в общей рубрике
новостей. Варианты — поиск WP (`/?s=raspored+rada`, порядок не гарантирован)
или ежемесячно обновлять ссылку руками. Оба плохие, оставлено пустым.

## Что изменит решение

- **Клики по ссылке** (`contact_type = doctor_schedule`). Если их почти нет,
  п. 1 закрыт окончательно.
- **График в кабинете клиники.** Если клиника сама ведёт график, за свежесть
  отвечает она, а не наш парсер. Это правильный путь к п. 1, но только при
  клиниках, которые реально пользуются кабинетом.
- **Автоматическая запись в прод** появится по другой причине — тогда п. 1
  станет заметно дешевле.
